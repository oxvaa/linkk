# Brand assets

- `netflix-logo.svg` contains the Netflix wordmark geometry used by the LINK Pro promotional prototype.
- `App.snack.js` renders the same vector inline with `react-native-svg` because a Snack created from a single `sourceUrl` does not automatically pull repository assets.
- Netflix is a trademark of Netflix, Inc. This LINK prototype does not itself provide a real Netflix subscription or redemption code.

- `verified-badge.webp` — user-supplied verified badge source asset.
- `verified-badge.png` — compact transparent fallback for Snack.
