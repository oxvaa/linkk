LINK 3.5 · Pulse — Official Chat UI
===================================

This build changes LINK Official from a custom page layout to a standard chat-style screen matching the rest of LINK.

Included:
- Standard chat header layout for LINK Official
- Smaller top identity like other chats
- Inline verified/read-only info banner
- Standard thread/message styling for official announcements
- Standard disabled composer area styled like the normal chat composer
- Empty state retained but moved into the chat thread
- Launcher cache build bumped to 352

- App.js
- App.snack.js
- index.html
